# Embedded Systems — STM32 (Uni)

Repository of exercises and projects for the **Embedded Systems** course, based on **STM32 Nucleo-G474RE** and **STM32CubeIDE**.

---

## Hardware

| Component | Detail |
| --- | --- |
| Board | Nucleo-G474RE |
| IDE | STM32CubeIDE |
| Serial communication | LPUART1 via ST-Link VCP (PA2 TX, PA3 RX) — **9600 baud** |
| Debug | ST-Link (SWD) |

## How to open a project

1. Launch **STM32CubeIDE**
2. **File → Import → Existing Projects into Workspace**
3. Select the project folder (the one containing `.project`, e.g., `fsm/simulazione2/simulazione2/`)
4. **Project → Build Project**
5. **Run → Debug** (ST-Link)

Each STM32 project is a separate Eclipse folder with a `Core/Src/` subfolder for the application code.

## FSM Architecture (course convention)

Typical cycle in `FSM_step()`:

1. **`read_inputs()`** — inputs snapshot (buttons, UART flags, timers, …)
2. **`update_state()`** — transitions and actions (Moore)
3. **`HAL_Delay`** to match `FSM_CYCLE_DURATION`

| Category | Examples |
| --- | --- |
| **Device** | `led_t*`, `button_t*`, `timer_t*` |
| **Input** | `button`, `button_last`, `buffer_ready`, `alarm` |
| **Memory** | `state`, `t_start`, `rx_buffer`, `prompt_sent` |
| **Output** | `led_on/off`, servo duty, UART messages |

Full details: [`fsm/FONDAMENTALI_ESAME.txt`](https://www.google.com/search?q=fsm/FONDAMENTALI_ESAME.txt)

## UART in interrupt (checklist)

* Arm `HAL_UART_Receive_IT` on state entry (or in init)
* In `HAL_UART_RxCpltCallback`: process byte + **always re-arm**
* Ignore `\r` and `\n`
* In `HAL_UART_TxCpltCallback`: only set `uart_tx_completed = 1`
* Shared flags IRQ ↔ main: **`volatile`**
* Messages with numbers: `snprintf` → static buffer → `Transmit_IT`

## Debug

| Problem | What to check |
| --- | --- |
| RX not received | Is `Receive_IT` armed? `hlpuart1.RxState == 34` (BUSY_RX)? Breakpoint in `HAL_UART_RxCpltCallback` |
| Live Expressions at 0 | Use `fsm.rx_index` (with a dot), not `fsm_rxindex` |
| Flags not updating | Missing `volatile` keyword |
| TX only works once | Check `uart_tx_completed` in `TxCpltCallback` |
